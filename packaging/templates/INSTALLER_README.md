ALTR STREAM INSTALLER

Choose the installer for your operating system:

Windows (Native Graphical Setup)
  Primary:
    Altr-Stream-Installer.exe
    Double-click Altr-Stream-Installer.exe to run the native setup wizard.
  Script / Terminal Fallback:
    Altr-Stream_Windows_Installer.bat

macOS (Native Graphical Setup)
  Primary:
    Altr-Stream_macOS_Installer.app.zip
    Unzip the archive and double-click "Altr Stream Installer.app" in Finder.
  Script / Terminal Fallback:
    Altr-Stream_macOS_Installer.command

Linux (Unified Installer)
  Altr-Stream_Linux_Installer.sh
  Run:
    chmod +x Altr-Stream_Linux_Installer.sh
    ./Altr-Stream_Linux_Installer.sh

Manual / Server Deployment (Docker Compose)
  altr-stream-v1.0.0-beta-deployment.tar.gz (or .zip)
  Extract the archive and run: docker compose up -d
